# 📊 onet-chiangmai-standards-analytics
## การวิเคราะห์แนวโน้มคะแนนเฉลี่ยถ่วงน้ำหนักรายมาตรฐานการเรียนรู้ O-NET (2565 - 2568)
### สำนักงานศึกษาธิการจังหวัด เชียงใหม่

ระบบสารสนเทศเชิงโต้ตอบ (Interactive Analytics Dashboard) สำหรับการวิเคราะห์และนำเสนอสารสนเทศแนวโน้มคะแนนเฉลี่ยถ่วงน้ำหนักผลการทดสอบทางการศึกษาระดับชาติขั้นพื้นฐาน (O-NET) ประจำปีการศึกษา 2565 – 2568 ระดับชั้นประถมศึกษาปีที่ 6 (ป.6) และมัธยมศึกษาปีที่ 3 (ม.3) จำแนกรายมาตรฐานการเรียนรู้และรายสังกัดสถานศึกษา

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Highlights)

1. **กราฟแนวโน้มคะแนนเฉลี่ยถ่วงน้ำหนักรายมาตรฐาน (Individual Standard Trend Line Graphs)**:
   * กราฟเส้นแสดงพัฒนาการ 4 ปีย้อนหลัง (2565 - 2568) สเกลคงที่ 0 - 100
   * ตัวเลขคะแนนเฉลี่ยลอยเด่นชัดอยู่บนจุดหมุดในแต่ละปีการศึกษา
   * ระบุจำนวนผู้เข้าสอบจริงกำกับไว้ในแกน X ของทุกปี
   * กล่องสรุปทิศทางตัวชี้วัด (คำนวณอัตราการปรับตัวเพิ่มขึ้น / ชะลอตัวลง อัตโนมัติ)
2. **บทสรุปและข้อเสนอแนะเชิงลึกทางการศึกษา (Macro Trend Analysis - White Theme)**:
   * 🟢 **จุดแข็งกระบวนการสาระ (Highlights):** สรุปมาตรฐานที่ทำคะแนนสะสมสูงสุดและมาตรฐานที่มีอัตราเร่งเติบโตต่อเนื่อง
   * ⚠️ **จุดวิกฤตที่สมควรได้รับการเร่งพัฒนา (Critical Areas):** ระบุมาตรฐานที่มีคะแนนเฉลี่ยรั้งท้ายเพื่อชี้เป้าแก้ปัญหา
   * 🎯 **แผนปฏิบัติการนโยบายรายสถานศึกษา (Action Plan):** แนวทางการขับเคลื่อน 3 ข้อสำหรับการนิเทศและฝ่ายบริหาร
3. **การปรับแต่ง UX/UI และ Accessibility**:
   * 🔤 ปรับขนาดตัวอักษรได้ 3 ระดับ (เล็ก / กลาง / ใหญ่)
   * 🎨 สลับธีมสีเทรนด์ 2027 ได้ 3 ธีม (*Digital Indigo, Neo Terracotta, Tech Teal*) พร้อมแถบพื้นหลังสีพาสเทลจาง ๆ สบายตา
   * 🟦 **ปุ่ม ป.6 (สีฟ้า)** และ 🟩 **ปุ่ม ม.3 (สีเขียว)**
   * 🏠 **ปุ่มหน้าหลัก (Home)** เริ่มต้นที่ ป.6 พร้อมรีเซ็ตตัวเลือกวิชาและสังกัดให้เริ่มต้นใหม่อย่างเป็นระบบ
4. **ระบบตัวกรองอัจฉริยะ (Interactive Filters)**:
   * ตัวเลือกมาตรฐานการเรียนรู้แบบ Dropdown แสดงเฉพาะมาตรฐานของวิชาที่เลือก

## 🌐 ขั้นตอนการนำขึ้น GitHub และเชื่อมต่อ Vercel

### 1. นำขึ้น GitHub Repository
```bash
# 1. กำหนดค่าเริ่มต้น Git
git init

# 2. เพิ่มไฟล์ทั้งหมด
git add .

# 3. บันทึก Commit
git commit -m "feat: release onet-chiangmai-standards-analytics dashboard"

# 4. ตั้งชื่อ Branch หลักเป็น main
git branch -M main

# 5. เชื่อมต่อไปยัง Repository ของท่านบน GitHub (เปลี่ยน USERNAME ให้เป็นชื่อบัญชีของคุณ)
git remote add origin https://github.com/USERNAME/onet-chiangmai-standards-analytics.git

# 6. Push ไฟล์ขึ้น GitHub
git push -u origin main
```

### 2. เชื่อมต่อ Vercel (Auto Deploy)
1. ไปที่เว็บไซต์ **[vercel.com](https://vercel.com)** แล้วเข้าสู่ระบบด้วยบัญชี GitHub
2. คลิกปุ่ม **"Add New..."** ➔ **"Project"**
3. เลือก Repository `onet-chiangmai-standards-analytics` แล้วกด **"Import"**
4. ในส่วน **Framework Preset** ให้เลือกเป็น **"Other"** (ระบบจะอ่านไฟล์ `vercel.json` และ `index.html` อัตโนมัติ)
5. คลิกปุ่ม **"Deploy"**
6. เว็บไซต์จะเปิดใช้งานออนไลน์ พร้อมได้ URL เช่น `https://onet-chiangmai-standards-analytics.vercel.app` ทันที!
